Frequently Asked Questions

How does Polish write changes back to my files?

Polish watches your CSS files and uses PostCSS to parse and surgically update declarations. It preserves your formatting, comments, and file structure.

Does it work with preprocessors like Sass or Less?

Polish operates on compiled CSS files. If you're using a build tool that outputs .css files, Polish can edit those. Direct .scss/.less editing is on the roadmap.

Can I use it with frameworks like React or Vue?

Yes. Polish proxies your dev server and injects the overlay. It works with any framework that serves HTML pages — React, Vue, Svelte, plain HTML, anything.

What happens if I edit a shorthand property like border?

Polish expands shorthands into their longhand equivalents and writes the specific property you changed. Your shorthand declaration stays intact.

Is my code safe? Can Polish corrupt my files?

Polish uses atomic writes and validates all changes before flushing to disk. It only modifies the specific declaration you changed — nothing else in the file is touched.
